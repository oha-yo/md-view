# md-view

フォルダを選ぶと、その下の tree を表示し、テキストや Markdown を**別の画面**で見るツールです。Markdown はプレビューで見られ、Mermaid の図も描かれます。ファイルはブラウザの中で読むだけで、どこにも送りません。

## 使い方
1. **https://md-view.oha-yo.com/** を Chrome か Edge で開く。または、このリポジトリを手元に置いて `md-view.html` を開く（ダブルクリックで開けます。ネットにつながっていなくても動きます）。
2. 「フォルダを選ぶ」でフォルダを選ぶか、フォルダを画面にドラッグして落とす。
3. tree のファイル名を押すと、別の画面が開く。

| ファイルの種類 | tree での表示 |
|---|---|
| Markdown（.md など） | ファイル名か目のアイコンでプレビュー、紙のアイコンでテキスト。別画面の右上のボタンで切り替えられる |
| HTML（.html・.htm・.xhtml） | Markdown と同じ。プレビューは枠の中にページとして出す（下の「HTML のプレビュー」） |
| テキスト | ファイル名でテキスト（行番号付き） |
| バイナリ（画像・zip・Office など） | 灰色の名前だけ（リンクなし） |

- **並び**：tree の上で、名前（初期値）・更新日時（新しい順）・大きさ（大きい順）から選ぶ。フォルダはいつも先。名前の並びはエクスプローラーと同じ（大文字・小文字を区別せず、名前の中の数字は数として比べる：`v2` → `v10`）。フォルダの更新日時は中のいちばん新しいファイルの日時で、大きさの並びのときフォルダは名前の順。選んだ並びは覚えておき、コピーと保存もその並びになる。
- **tree を保存**：すべてのフォルダを開いた状態で、`.txt` か `.md` に保存する（`.md` のときはコードの囲みに入れる）。
  - 「**更新日時を付ける**」に印を付けると、各行の先頭に `2026/11/15 13:51` の形で更新日時を出す。この切り替えは、**画面の tree と「tree をコピー」にも効く**（画面では左端にそろえた列で出す）。
  - フォルダの日時は、**中のいちばん新しいファイルの日時**。ブラウザはフォルダそのものの日時を教えないため。中にファイルがないフォルダは空白になる。
- **tree をコピー**：**今見えている状態**でコピーする。閉じているフォルダは、中身を省いて `css/  …（省略：ファイル 1）` のように 1 行にする。
- **場所（フルパス）**：選んだフォルダのフルパスを tree の上に出す。横のアイコンでコピーできる。
  - ブラウザはフルパスをページに教えないので、**初めてのフォルダでは一度だけ貼り付けて「覚える」**を押す（エクスプローラーでフォルダを選んで Ctrl+Shift+C でコピーできる。前後の `"` はそのままでよい）。
  - 覚えたフォルダの**下のフォルダ**を選んだときは、自動でフルパスが出る。よく使う親のフォルダ（例：`D:\claude-pj`）を一度覚えさせておくと楽。
  - 間違えたら「直す」で貼り直す。覚えたものは、このブラウザの中（IndexedDB）にだけ置く。
  - 別画面の上の帯にも、ファイルのフルパスを出す。
- **探す**：tree の上で「ファイル名」か「中身（grep）」を選んで、文字を入れる。見つかったファイルだけが tree に残る（探している間はフォルダをすべて開き、やめると元の開き方に戻る）。
  - ファイル名：空白で区切ると「かつ」。`*` と `?` が使える（例：`*.md`）。`/` を含むとパス全体で探す（例：`docs/`）。大文字・小文字は区別しない。
  - 中身（grep）：テキスト・Markdown・HTML の中を探す（バイナリと 5 MB より大きいファイルは探さない）。「大文字・小文字を区別」「正規表現」を選べる。tree の下に一致した行が出て、行を押すと**その行に色を付けてテキストで開く**。「grep 結果をコピー」でチャットに貼れる形でコピーする。
  - **更新日**：from〜to で絞り込む。from だけならその日以降（その日を含む）、to だけならその日以前（その日を含む）。空なら絞り込まない。ファイル名・中身の検索と組み合わせられる（grep は、日付に合うファイルの中だけを探す）。日付は読み込んだときのもの（ファイルを足したり変えたりしたら「読み直す」）。
  - 探している間の「tree をコピー」は、見つかったファイルだけを出す。Esc か「×」でやめる。
- **外すフォルダ**（設定）：初期値は空（すべて出す）。`.git, node_modules` のようにカンマで区切って入れる。
- **自動更新**：開いている別画面のファイルが変わったら、1.5 秒ほどで表示を更新する（スクロールの位置はそのまま）。
- **読み直す**：フォルダにファイルを足したり消したりしたら押す。
- 文字コードは UTF-8・UTF-16・Shift_JIS・EUC-JP を自動で判定する。
- 拡張子でわからないファイルは、先頭に NUL 文字があればバイナリとみなす。
- Markdown の中の ` ```html-raw ` で囲んだところは、中身をそのまま HTML として出す（ブログの下書きで図の SVG を書く囲み）。スクリプトや `onclick` などは取り除く。テキストで見るときは、囲みのまま出す。
- Markdown の中の相対パスの画像は、選んだフォルダの中から読んで表示する。フォルダの中の別のファイルへのリンクは、同じ画面で開く。

## Markdown のプレビューで描くもの
| 書き方 | 出し方 |
|---|---|
| ` ```mermaid ` | Mermaid の図 |
| ` ```math `・`$$ … $$`・`$ … $` | 数式（KaTeX。GitHub と同じ書き方）。「100$」「$5 と $10」のようなお金の書き方は数式にしない |
| ` ```sql ` など言語を付けたコード | 色付け（highlight.js）。言語がわからないものは色なし |
| `> [!NOTE]`・`[!TIP]`・`[!IMPORTANT]`・`[!WARNING]`・`[!CAUTION]` | GitHub のアラート。色付きの囲み（補足・ヒント・重要・注意・警告） |
| ` ```html-raw ` | 中身をそのまま HTML として出す |

- テキストで見るときも、拡張子（.java・.sql・.ps1・.md・.html など）に合わせて色を付ける。1 MB より大きいテキストは色なし。
- Mermaid・KaTeX・highlight.js は、ページを開いたときには読み込まず、初めて使うときに読み込む。

## HTML のプレビュー
- **スクリプトは動かしません**（`<script>` や `onclick` など）。見た目を確かめるためのものです。
- フォルダの中の画像と CSS（`<link rel="stylesheet">`）は読み込んで反映します。CSS の中の `url()`（背景の画像やフォント）は読み込みません。
- フォルダの中の別のファイルへのリンクは、同じ画面で開きます。外へのリンクは新しいタブで開きます。
- 自動更新のときも、スクロールの位置はそのままです。

## 構成
- `md-view.html`・`md-view.css`：画面と見た目
- `js/`：本体。役割ごとに分けている（ふつうの `<script>` で、この順に読む）

  | ファイル | 役割 |
  |---|---|
  | `core.js` | 決まった値・アプリの状態（`state`）・小さな道具（文字・日時・パス・アイコン） |
  | `files.js` | ファイルの種類の判定・文字コード・フォルダの読み込み |
  | `tree.js` | tree の表示・保存・コピー |
  | `find.js` | ファイル名・中身（grep）・更新日で探す |
  | `render.js` | Markdown（Mermaid・数式・色付け・アラート）と HTML のプレビュー |
  | `viewer.js` | 別画面（テキスト・プレビューの切り替え・自動更新） |
  | `fullpath.js` | フルパスを覚える（IndexedDB） |
  | `main.js` | 入口（フォルダを選ぶ・読み込む・画面の準備） |
- `lib/`：marked 15.0.12・DOMPurify 3.4.18・Mermaid 11.17.2・KaTeX 0.16.47・highlight.js 11.12.0（ネットに出ないように、同じ場所に置いている。ライセンスも同じフォルダ）
  - `highlight.min.js` は、highlight.js のよく使う言語のまとめに、PowerShell・bat（dos）・Dockerfile・PostgreSQL・Groovy・Gradle・properties・Apache・nginx を足したもの。`highlight-theme.js` は GitHub の見た目の CSS を文字にしたもの（別画面に書き込むため）
- `test/`：回帰テスト（`regress.html`・`regress.js`・`expected.json`）、テスト用のサーバー（`serve.py`）、確認用のフォルダ（`sample/`。中身はダミー）
- `deploy/.htaccess`：https://md-view.oha-yo.com/ で公開するための設定

## Web で使う（https://md-view.oha-yo.com/）
- サーバーには、`md-view.html`・`md-view.css`・`js/`・`lib/` と `deploy/.htaccess` を置く（`test/` は置かない）。
- `md-view.html` の写しを `index.html` という名前でも置く（`md-view.html` を直したら、こちらも置き直す）。エックスサーバーは前段のサーバー（nginx）が `/` に `index.html` を返してキャッシュするので、`.htaccess` の `DirectoryIndex` だけでは入口が初期ページになることがあった。キャッシュが残ったときは、サーバーパネルの「Xアクセラレータ」を一度無効にして戻すと消える。
- `.htaccess` で **CSP**（ブラウザに守らせる決まり）を付けている。スクリプトはこのサイトに置いたものだけ、fetch などの外への通信は禁止、画像は自分のサイトと選んだフォルダから読んだものだけ。md-view の不具合や、開いたファイルの中に何か仕掛けがあっても、ブラウザが外に送らせない。
- そのため、Markdown の中の外の画像（`https://…`）は表示されない。
- ブラウザの中に保存するもの（設定・覚えたフルパス）は、URL ごとに分かれる。`file://` で開いたときに覚えさせたフルパスは、Web では覚え直しになる。

## 気をつけること
- 「読み直す」と自動更新は、フォルダを選べるブラウザ（Chrome・Edge）だけで使えます。Firefox はフォルダを一度読むだけです。
- 別の画面はポップアップで開きます。止められたら、ブラウザでこのページのポップアップを許可してください。
- Markdown の中の HTML は、DOMPurify で危ないもの（スクリプトなど）を取り除いてから表示します。
